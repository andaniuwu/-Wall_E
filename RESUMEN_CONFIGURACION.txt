PASO 1: CREAR USUARIO LIMITADO
═════════════════════════════════════════════════════════════════════════════════

Comando 1:
  sudo useradd -m -s /bin/bash wall-e-user

  ¿Qué hace?
    - useradd: crea un nuevo usuario
    - -m: crea la carpeta home (/home/wall-e-user)
    - -s /bin/bash: establece bash como shell

Comando 2:
  sudo passwd wall-e-user

  ¿Qué hace?
    - Establece contraseña para wall-e-user
    - Ingresa 2 veces la contraseña que prefieras

PASO 2: CONFIGURAR AUTOLOGIN PARA wall-e-user
═════════════════════════════════════════════════════════════════════════════════

Comando:
  sudo nano /etc/lightdm/lightdm.conf

Ubicación donde editar (línea ~100):
  [Seat:*]
  autologin-user=wall-e-user
  autologin-user-timeout=0
  #type=local
  #pam-service=lightdm
  ...

¿Qué hace?
  - autologin-user=wall-e-user: este usuario entra automáticamente
  - autologin-user-timeout=0: entra inmediatamente sin esperar

Guardado:
  Ctrl+O (write out)
  Enter (confirmar nombre)
  Ctrl+X (exit)

═════════════════════════════════════════════════════════════════════════════════
PASO 4: PROTEGER ARCHIVOS DEL PROYECTO
═════════════════════════════════════════════════════════════════════════════════

Comando 1:
  cd /home/rasp_raccoon_berry/Documents/Wall_E_UV-and-Voltage-sense

  ¿Qué hace?
    - Navega a la carpeta del proyecto

Comando 2:
  sudo chmod -R 550 .

  ¿Qué hace?
    - chmod: cambia permisos de archivos
    - -R: recursivo (todos los archivos y subcarpetas)
    - 550: 
      * 5 = dueño puede leer (r) y ejecutar (x), no escribir
      * 5 = grupo puede leer y ejecutar
      * 0 = otros no tienen permisos
    - . = carpeta actual

Comando 3:
  sudo chown -R wall-e-user:wall-e-user .

  ¿Qué hace?
    - chown: cambia dueño de archivos
    - -R: recursivo
    - wall-e-user:wall-e-user = dueño:grupo
    - . = carpeta actual

  RESULTADO:
    ✓ wall-e-user es dueño
    ✓ Puede leer y ejecutar, no modificar
    ✓ El código está protegido
